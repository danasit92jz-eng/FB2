# Logic Box
## Project Name
Logic Box – Pattern Generator and Number Analyzer
## Objective
The project contains two main features:
1. Pattern Generator
2. Number Analyzer
The project demonstrates the use of for loops, while loops, nested loops,
range(), if-else statements, break, continue and pass statements.
## Features
### 1. Pattern Generator
The program generates a right-angled triangle pattern based on the number
of rows entered by the user.
### 2. Number Analyzer
The program accepts a start and end number from the user.
It then:
- Displays whether each number is Odd or Even.
- Calculates the sum of all numbers in the range.
- Uses the range() function.
- Uses a for loop for number analysis.
### 3. Menu-Driven Interface
1. Generate Pattern
2. Analyze Numbers
3. Exit
### 4. Input Validation
The program checks:
- Row count must be greater than zero.
- End number must be greater than start number.
- Invalid menu choices are handled with an appropriate message.
## Technologies Used
- Python 3
- for loop
- while loop
- Nested loops
- range() function
- if-else statements
- break statement
- continue statement
- pass statement

Download this project from GitHub or clone the repository.
